# Fonts

The woff2 files in this directory are self-hosted copies of [Geist and Geist Mono](https://github.com/vercel/geist-font) (variable, latin and latin-ext subsets), taken from the npm packages `@fontsource-variable/geist@5.3.0` and `@fontsource-variable/geist-mono@5.3.0`. Both typefaces are licensed under the SIL Open Font License, Version 1.1 — see [OFL-geist.txt](./OFL-geist.txt) for the full license text including the copyright notice.
